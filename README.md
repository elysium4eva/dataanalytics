# Data Analytics in Marketing

Course site for **Data Analytics in Marketing**, the analytics module of *International Marketing Strategy*
(Course 0205360001), Shenzhen University, 2026.

Six chapters, English lecture notes built with LaTeX Beamer (Shenzhen University theme), runnable Python and
sample data:

| Chapter | Title | Frames |
|---|---|---|
| 1 | Introduction: big data and the AI landscape | 82 |
| 2 | Data sourcing: foundations of data science | 95 |
| 3 | Data preparation | 92 |
| 4 | Data description and visualization | 102 |
| 5 | Introduction to machine learning | 104 |
| 15 | Big data in marketing | 50 |

Chapter numbers follow the *Big Data Analytics* course this material is adapted from.

- Course home: `index.html`
- Syllabus: `syllabus.html`
- Sample data and code: `code.html` (`code/chapter05/`)
- Slides: `files/*.pdf`

Every deck keeps the section structure, frame count and figures of the Chinese original; only the language and
the course framing change. Chapter 5 ships twelve programs with one comment per line and a single
`python run_all.py` that rebuilds every table, figure and run log.
