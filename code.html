Sample Data & Code

Chapter 5 ships twelve programs, their sample data and their outputs. Every line carries a comment; one command rebuilds all tables and figures.

Programs
12 Python scripts
Sample data
23 CSV files, fixed seeds
Runtime
Comfortably under a minute on a laptop
Licence
Teaching use; data are synthetic or public

How to run it

# 1. get the folder (link below), then
pip install -r requirements.txt

# 2. rebuild every table, figure and run log
python run_all.py

# 3. or run one program on its own, e.g.
python l5_02_cv_and_leakage.py

Each program writes a l5_run_log_*.json next to its outputs: script name, random seed, data digest, metrics and artefact list. That record is what makes a result reproducible — and it is what the model card in Chapter 5 is built from.

Chapters 1–4 do not need a code bundle to be followed: their worked examples are built into the slides, and every sample used there is generated by the deck's own listing. If you want the raw files for those chapters, ask in class and they will be posted with the assignment.

Conventions

  • One comment per line. The programs are written to be read aloud in class, not only run.
  • Seeds everywhere. random_state=42 for splits and models, seed 20260506 for the sample generator.
  • No hidden state. Each script starts from the CSV files, never from another script's output.
  • Outputs on disk. Tables go to data/, figures to figures/, run logs and model cards to artifacts/.
  • Fail loudly. Missing columns or changed dtypes raise instead of silently producing an empty chart.
