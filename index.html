Assessment Within the Host Course

The analytics module is assessed through the host course's project. Full detail, the eight project requirements and the complete rubric are in the syllabus.

ComponentWeightHow analytics enters it
Participation and in-class work10%Exercises on the sample data; code review in class
Project oral presentation30%Analytics question, data source and preliminary evidence
Final essay and evidence package60%20% of the project rubric is “Data analytics and visualization”: sourcing, cleaning, analysis, figures, reproducibility

What a good analytics submission shows

A question that can be tested, data whose licence you can state, a split that blocks leakage, a baseline you beat (or honestly fail to beat), calibrated probabilities where decisions depend on them, and figures that survive being read without the text.

AI use disclosure

Every submission carries an AI-use appendix: tool and model, prompts or workflow, inputs, the outputs you used, how you verified them, what you corrected, and which decisions were yours. Unverified AI output counts as academic misconduct.

Materials

Core reading

Géron, A. (2022). Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow, 3rd ed., Ch. 1–3. Plus the lecture notes on this site, which are self-contained.

Methods references

Hastie, Tibshirani & Friedman, The Elements of Statistical Learning, Ch. 7; James et al., An Introduction to Statistical Learning; Mitchell, Machine Learning (1997) for the E/T/P definition.

Marketing analytics

Palmatier & Sridhar, Marketing Strategy: Based on First Principles and Data Analytics; Lilien & Rangaswamy, Marketing Engineering for conjoint and choice models.

Tooling

scikit-learn user guide and estimator map; XGBoost and LightGBM documentation; Optuna; MLflow. All open source and free.

Ethics and compliance

Model Cards (Mitchell et al., 2019); the EU AI Act high-risk list; the university's rules on personal data and informed consent.

Data

Every chapter ships sample data built for teaching, so results reproduce exactly: fixed seeds, fixed splits, one command to rebuild all figures.
